# PFCえらび

これまでと同じStreamlitで動く、スマートフォン向けの商品比較アプリです。

## 設置
1. 新しいGitHubリポジトリへ app.py と requirements.txt をアップロード。
2. Streamlit Community Cloudで、そのリポジトリの app.py を指定してデプロイ。
3. APIキー・Supabase設定は不要です。

既存の別アプリのapp.pyを上書きせず、新しいリポジトリに設置してください。
ローカル実行は `pip install -r requirements.txt` の後 `streamlit run app.py`。

## 機能
- セブンイレブン／ローソン／ファミリーマート／イオン・トップバリュ／その他スーパー別に検索
- 商品名・ジャンル・たんぱく質下限・脂質上限・カロリー上限・予算
- たんぱく質順・設定したPFC比率への近さ・価格順・100円当たりP量順
- お気に入り、複数商品の量を指定した合計PFC
- 商品追加・編集、公式ページの栄養表示確認、JSONバックアップと復元

## 商品情報の範囲
初期登録6件。2026年9月6日に公式商品ページで確認した情報を内蔵しています。
全商品をリアルタイム収集する検索ではありません。在庫・販売継続を保証するものではありません。
商品カードに出典URL・確認日・注意点を表示します。未確認値は推定しません。
ファミリーマート2商品は商品名のP量のみ確認済みで、F/Cは未確認です。
セブンのプレーンチキンは栄養単位と脂質が未確認です。購入前にパッケージで確認してください。
その他スーパーは初期商品未登録。実際の商品表示を確認し、店舗名をメモに入力して追加できます。
公式ページ取得は4社の許可したホストに限定。取得失敗でも手入力は可能です。
外部Web検索はブラウザで開きます。結果の自動登録は行いません。

## 計算
PFC比率 = 各成分の換算エネルギー ÷ (P×4+F×9+C×4)。
目標への近さは3比率の絶対差合計が小さい順。初期目標20:25:55は比較用設定で、健康評価ではありません。
100g表示と1包装表示を混同しないでください。ヨーグルトは公式100g値の4倍を1包装400gとして登録。
表示カロリーは商品表示を使い、PFCから逆算しません。
条件判定に必要な値が未確認の商品は該当条件の検索から除外。
合計に未確認値が含まれる場合、その項目の合計は未確認と表示。

## 保存
ログインは不要。入力データはStreamlitの接続セッション内に保持されます。
ブラウザ再接続・サーバー再起動で消える場合があるため、「保存・復元」でJSONを保存してください。
次回はJSONを読み込んで復元します。アカウント同期・恒久的なサーバー保存はありません。
